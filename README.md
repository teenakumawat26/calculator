# 🧮 Simple Calculator

A clean and responsive calculator built with HTML, CSS & JavaScript.

**Live Demo:** https://teenakumawat26.github.io/calculator/

### ✨ Features
- Basic operations: +, -, *, /
- Clear (C) and Delete functionality
- Responsive design - works on mobile & laptop
- Keyboard support
- Clean UI

### 🛠️ Tech Stack
- HTML5
- CSS3
- JavaScript
